10 modern CSS tricks you should learn today

Home Blog Modern CSS tricks
Arash Moghadam October 4, 2026 8 min read 3 comments

CSS has changed more in the last few years than ever before. Much of what used to need JavaScript or complicated hacks can now be done with a few lines of plain CSS. In this article we go through 10 practical features that modern browsers support well.

1. The parent selector :has()

For years developers wished they could style an element based on its children. With :has() that is now possible: 

/* a card with an image gets a different layout */
.card:has(img) {
  display: grid;
  grid-template-columns: 200px 1fr;
}

2. Container queries

Instead of depending on the page width, components can respond to the width of their parent. That means truly reusable components.

“The best code is the code you never write. Modern CSS lets us do more with less code.” — a member of the CSS Working Group

Key takeaways

  • Use cqi units to size things relative to the container.
  • Give every container a clear name with container-name.
  • Combine container queries with media queries; don't replace them.

3. Native nesting

You no longer need Sass to write nested styles. Native CSS now supports nesting, which makes your code more readable and tidier. It is still a good idea to keep nesting under three levels deep.

In the next part of this article we look at scroll-driven animations, View Transitions and a few more tricks. If you have any questions, ask them in the comments!
