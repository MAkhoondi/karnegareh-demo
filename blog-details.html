۱۰ ترفند CSS مدرن که باید همین امروز یاد بگیرید

خانه وبلاگ ترفندهای CSS مدرن
آرش مقدم ۱۲ مهر ۱۴۰۵ ۸ دقیقه مطالعه ۳ دیدگاه

CSS در چند سال اخیر بیش از هر زمان دیگری تغییر کرده است. بسیاری از کارهایی که قبلاً به جاوااسکریپت یا ترفندهای پیچیده نیاز داشتند، حالا با چند خط CSS ساده انجام می‌شوند. در این مقاله ۱۰ ویژگی کاربردی را مرور می‌کنیم که مرورگرهای مدرن به‌خوبی از آن‌ها پشتیبانی می‌کنند.

۱. انتخابگر والد با ‎:has()‎

سال‌ها آرزوی توسعه‌دهندگان این بود که بتوانند والد یک عنصر را بر اساس فرزندانش استایل دهند. حالا با :has() این کار ممکن شده است: 

/* کارتی که تصویر دارد، چیدمان متفاوتی بگیرد */
.card:has(img) {
  display: grid;
  grid-template-columns: 200px 1fr;
}

۲. کوئری‌های کانتینر

به‌جای وابستگی به عرض صفحه، کامپوننت‌ها می‌توانند بر اساس عرض والد خود واکنش نشان دهند. این یعنی کامپوننت‌هایی واقعاً قابل استفاده مجدد.

«بهترین کد، کدی است که نوشته نمی‌شود. CSS مدرن به ما اجازه می‌دهد با کد کمتر، کار بیشتری انجام دهیم.» — یکی از اعضای گروه کاری CSS

نکات کلیدی این بخش

  • از واحدهای cqi برای اندازه‌دهی نسبت به کانتینر استفاده کنید.
  • برای هر کانتینر یک نام مشخص با container-name تعریف کنید.
  • کوئری‌های کانتینر را با Media Query ترکیب کنید، نه جایگزین.

۳. تودرتو نویسی بومی (Nesting)

دیگر برای نوشتن استایل‌های تودرتو به Sass نیاز ندارید. CSS بومی حالا از Nesting پشتیبانی می‌کند و کدهای شما خواناتر و مرتب‌تر می‌شوند. البته همچنان توصیه می‌شود عمق تودرتو را کمتر از سه سطح نگه دارید.

در قسمت بعدی این مقاله، به سراغ انیمیشن‌های وابسته به اسکرول، View Transitions و چند ترفند دیگر می‌رویم. اگر سؤالی دارید، در بخش دیدگاه‌ها بپرسید!
